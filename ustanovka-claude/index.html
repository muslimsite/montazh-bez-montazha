Как установить Claude

Пошагово, без сложных слов. Займёт около 15 минут, и после этого Claude будет монтировать рилс прямо на твоём компьютере.

  • Почта для аккаунта.
  • Платная подписка Claude. На бесплатном тарифе нет вкладки Code, в которой Claude монтирует.

Установка

Проверь свою страну

Claude работает не во всех странах. Список стран, где он доступен, есть на сайте Anthropic.

Открыть список стран

Создай аккаунт

Зайди на claude.ai и зарегистрируйся через почту или аккаунт Google.

Оформи подписку

В аккаунте открой настройки, раздел оплаты, и выбери Pro или Max. Начать можно с Pro, перейти на Max можно в любой момент.

Скачай приложение

Выбери свой компьютер:

Скачать для MacСкачать для Windows

Если у тебя Windows на процессоре ARM (редкие ноутбуки), вот отдельный файл.

Установи и открой

  • Mac: открой скачанный файл и установи. Потом запусти Claude из папки «Программы».
  • Windows: запусти скачанный установщик. Потом открой Claude через меню «Пуск».

Войди и открой вкладку Code

Войди в тот же аккаунт. Вверху слева, в боковой панели, нажми вкладку Code. Если видны только значки, наведи на них мышку, появятся названия.

Создай папку и выбери её

Создай на компьютере папку «Рилс» и положи в неё папку-набор с интенсива. Потом в Claude под полем для сообщения:

  • нажми первый переключатель и выбери вариант из группы Local, то есть «на моём компьютере»;
  • нажми кнопку рядом, выбери Open folder… и укажи папку «Рилс».

Реши, как часто Claude спрашивает разрешение

Под полем для сообщения есть переключатель режима:

  • Manual, стоит сначала: Claude спрашивает перед каждым действием, ты нажимаешь «разрешить» или «отклонить». Так спокойнее на первых порах.
  • Auto: Claude работает без постоянных вопросов, а рискованные действия сам останавливает. Удобно, когда уже освоилась.

Напиши первое сообщение

Скопируй и отправь, Claude сам проверит, что всё готово для монтажа:

Если что-то не получается

  • Нет вкладки Code. Проверь, что оформлена подписка Pro или Max, и обнови приложение: на Mac Claude → Check for Updates…, на Windows Help → Check for Updates…
  • На Windows пишет «Git is required». Сначала обнови приложение. Если не помогло, установи бесплатную программу Git for Windows и попробуй снова.
  • Нужно ли ставить что-то ещё? Нет, программировать и ставить дополнительные программы для начала не нужно. Всё остальное Claude поставит сам, когда попросишь, а ты только нажмёшь «разрешить».

Готово

Claude установлен. Дальше на уроке 1 делаем твой первый рилс.
